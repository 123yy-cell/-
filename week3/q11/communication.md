# 协作材料改写

## Issue：空白名称参数仍输出无效问候且正常退出
- 环境：操作系统版本待确认，Python 版本待确认，greetlab 版本 0.1.0
- 复现命令：`sdt-greet --name "   "`
- 期望结果：程序识别非法空白输入，以退出码 2 终止，不输出问候语
- 实际结果：程序正常执行并以退出码 0 退出，输出 `Hello,   !`

## 提交信息
**标题：修复空白名称参数未校验的问题**
正文：传入仅含空白字符的 `--name` 参数时，程序未执行合法性校验，直接输出无效问候并以 0 正常退出，不符合输入校验规范。本次修改在 main 函数中新增空白字符判断，去除首尾空白后为空则调用 `sys.exit(2)` 终止程序，确保非法输入可被调用方通过退出码识别。

## 评审意见
**[Blocking] 空白输入未做合法性校验**
- 具体行为：当前实现未对 `--name` 参数进行空白字符过滤，全空白名称可正常通过解析并输出结果。
- 风险：产生无意义的无效输出，调用方无法通过退出码区分合法与非法输入，下游依赖退出状态的流程会出现异常。
- 建议动作：补充空白字符校验逻辑，全空白输入时返回非零退出码；同步新增对应单元测试覆盖该场景，验证修复效果。
